# 시드니 여행 안내 앱

2027년 2월 6일(토)~13일(토) 시드니 여행(민기·재동·준열)용 웹앱입니다. 칭다오 앱과 같은 구조입니다.

## 고치는 곳

| 바꾸고 싶은 것 | `data.js`에서 찾을 곳 |
| --- | --- |
| 일정 시각·내용 | `days:`의 `items` |
| 식당·장소 설명 | `places:`의 `desc` |
| 구글 지도 검색어 | 각 장소의 `en` |
| 메뉴 | `menu: [ { en, ko, desc, image } ]` |
| 길 잃었을 때 | `lost:` |
| 식당 영어 | `phrases:` |
| 준비물 / 알아둘 점 | `checklist:` / `tips:` |

- 시각은 모두 시드니 시간(2월 서머타임, UTC+11)입니다. 한국 시간이면 `tz: "KST"`를 붙입니다.
- 공개 저장소로 바꾸면 사이트도 공개입니다. 예약 코드, 결제 금액, 카드 정보, 전화번호는 넣지 마세요.
- 반영이 안 되면 `sw.js`의 `VERSION` 숫자를 하나 올립니다.

## 미리 보기

주소 뒤에 `?now=`를 붙이면 그 시각(시드니 시간) 기준 화면을 봅니다.

- `…/?now=2026-12-01T12:00` — 여행 전
- `…/?now=2027-02-09T08:30` — 피시마켓
- `…/?now=2027-02-12T22:30` — 마지막 밤
